📝 To-Do List Web App

A simple To-Do List web application built using Node.js, Express.js, EJS, and RESTful routing.

This project helped me understand how backend applications work with Express, how to create and manage routes, how to use EJS for dynamic HTML pages, and how to implement CRUD operations.

🚀 Features
Create new posts/tasks
View all posts/tasks
View details of a specific post
Edit existing posts
Delete posts
RESTful routing
Dynamic pages using EJS
HTTP method override for PATCH and DELETE
Form data handling with Express
🛠️ Technologies Used
Node.js
Express.js
EJS
HTML
CSS
Method-Override
UUID
📚 What I Learned

Through this project, I practiced:

Creating an Express server
Working with GET, POST, PATCH, and DELETE routes
Using route parameters with req.params
Handling form data with req.body
Rendering dynamic content with EJS
Using EJS template syntax
Implementing CRUD functionality
Using method-override to support HTTP methods that HTML forms don't natively support
Organizing frontend and backend code
▶️ How to Run

Clone the repository:

git clone <your-repository-url>


Navigate into the project:

cd To-do


Install dependencies:

npm install


Start the server:

node index.js


Then open:

http://localhost:3000/posts
